## 도구

| 도구 | 역할 | 설정 위치 |
| --- | --- | --- |
| ruff | 린트 + 포매팅 | `pyproject.toml` `[tool.ruff]` |
| mypy | 정적 타입 검사 (strict) | `[tool.mypy]` |
| pytest | 테스트 + 커버리지 | `[tool.pytest.ini_options]`, `[tool.coverage.*]` |
| pre-commit | 커밋 시 자동 검사 | `.pre-commit-config.yaml` |

## 로컬 실행

```bash
make lint        # ruff check
make format      # ruff format (수정 적용)
make typecheck   # mypy
make test        # pytest + 커버리지
make check       # 위 전체 + 포맷 검사
make pre-commit  # 모든 파일에 pre-commit
```

`make` 가 없으면 (예: Windows):

```bash
uv run ruff check .
uv run ruff format .
uv run mypy
uv run pytest
```

## 규칙

- 린트 규칙 집합: `E, F, I, N, UP, B, SIM, PL, S, RUF`. 테스트는 `S101`, `PLR2004` 제외.
- 커버리지가 100% 미만이면 `pytest` 가 실패한다 (`--cov-fail-under=100`).
- mypy `strict = true`. 타입 무시는 `# type: ignore[코드]` 로 사유 코드를 명시한다.
- 줄 길이 100.

## pre-commit

`make setup` 또는 `uv run pre-commit install` 후 커밋 시 자동 실행된다. 훅: 공백·EOF 정리, YAML/TOML 검증, 512KB 초과 파일 차단, 병합 마커 검사, ruff(check + format), mypy.
