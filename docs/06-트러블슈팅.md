# 06 · 트러블슈팅

[← CI](05-ci.md) · [문서 목차](README.md) · [다음: 디렉터리 구조 →](07-디렉터리-구조.md)

---

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `uv: command not found` | uv 미설치 / PATH 누락 | 설치 후 `~/.local/bin` 을 PATH 에 추가하고 셸 재시작 |
| `uv sync` 가 `lockfile is out of date` | `pyproject.toml` 변경 후 락 미갱신 | `uv lock` 실행 후 커밋 |
| Windows 에서 CRLF diff 가 계속 생김 | 에디터가 CRLF 로 저장 | `.gitattributes` 가 LF 를 강제한다. `git add --renormalize .` 후 커밋 |
| pre-commit 훅이 실행되지 않음 | 훅 미설치 | `uv run pre-commit install` |
| mypy `Library stubs not installed` | 서드파티 타입 스텁 누락 | `uv add --dev types-<패키지>` 후 `uv lock` |
| Dev Container 빌드 후 인터프리터가 `.venv` 가 아님 | VS Code 캐시 | 명령 팔레트 → **Python: Select Interpreter** → `.venv/bin/python` |
| Docker 빌드가 `failed to solve` (cache mount) | 구형 Docker (BuildKit 비활성) | Docker 24 이상 사용, 또는 `DOCKER_BUILDKIT=1 docker build .` |
| `pytest` 가 `coverage failure: total ... under 100` | 커버리지 부족 | 누락 라인에 테스트 추가, 또는 합당할 때만 대상 코드에 `# pragma: no cover` |
| 기존 conda 환경과 충돌 | conda 가 활성화되어 있음 | `conda deactivate` 후 `uv` 사용. 이 저장소는 conda 를 쓰지 않는다 |
