# 01 · 빠른 시작

세 가지 방법 중 하나로 환경을 준비한다. 팀 표준은 **Dev Container** 다.

[문서 목차](README.md) · [다음: 개발 환경 →](02-개발-환경.md)

---

## 사전 조건

| 방법 | 필요한 것 |
| --- | --- |
| Dev Container | Docker, VS Code + Dev Containers 확장 |
| Docker | Docker |
| 로컬 | [uv](https://docs.astral.sh/uv/) |

## 방법 A — Dev Container

1. VS Code 로 저장소를 연다.
2. 명령 팔레트 → **Dev Containers: Reopen in Container**.
3. 컨테이너가 빌드되고 `uv sync` 로 의존성이 설치된다. `.venv` 인터프리터가 자동 선택된다.

## 방법 B — Docker

```bash
docker build -t setup1:local .
docker run --rm setup1:local
```

## 방법 C — 로컬

```bash
# uv 설치 — macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# Windows(PowerShell): irm https://astral.sh/uv/install.ps1 | iex

uv sync --frozen
uv run pre-commit install --install-hooks
```

`sh scripts/bootstrap.sh` 로 위 과정을 한 번에 실행할 수 있다.

## 확인

```bash
uv run pytest      # 테스트
make check         # lint + type + test 전체
```
