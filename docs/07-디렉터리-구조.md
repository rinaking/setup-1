## 규칙

- 코드는 `src/setup1/` 에 두고 노트북에서 `from setup1... import ...` 로 불러온다.
- `data/`, `models/` 의 내용물은 각 폴더의 `.gitignore`(자기 자신과 그 파일만 추적)가 차단한다. 그 `.gitignore` 가 폴더 구조를 유지한다.
- 비밀 값은 `.env`(커밋되지 않음)에 두고, 키 목록만 `.env.example` 에 유지한다.
