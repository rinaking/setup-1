## 잡

### `quality`

`ubuntu` · `macos` · `windows` × Python 3.13 매트릭스.

1. `uv sync --frozen` — 락 그대로 설치.
2. `ruff check` — 린트.
3. `ruff format --check` — 포맷 검사.
4. `mypy` — 타입 검사.
5. `pytest` — 테스트 + 커버리지 100% 확인.

### `docker`

`Dockerfile` 로 런타임 이미지를 빌드하고 `docker run` 으로 스모크 테스트한다.

## Dependabot

`.github/dependabot.yml` 이 매주 다음의 업데이트 PR 을 만든다: uv 의존성, GitHub Actions, Docker 베이스 이미지, Dev Container.

## 실패 시

| 상황 | 대처 |
| --- | --- |
| `quality` 실패 | 로그의 실패 단계를 로컬에서 `make lint` / `make typecheck` / `make test` 로 재현 |
| 특정 OS 만 실패 | 경로 구분자, 줄바꿈(CRLF), 파일 인코딩 확인 |
| `uv sync` 가 `lockfile is out of date` | `pyproject.toml` 변경 후 `uv lock` 미실행 → `uv lock` 후 커밋 |
