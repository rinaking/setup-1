## 의존성 관리 — uv

의존성은 [uv](https://docs.astral.sh/uv/) 로 관리한다.

- **선언** — `pyproject.toml` 의 `[project].dependencies`(실행), `[dependency-groups].dev`(개발 도구).
- **고정** — `uv.lock` 에 모든 전이 의존성의 정확한 버전과 해시가 기록된다. 플랫폼 무관 단일 파일이다.
- **재현** — `uv sync --frozen` 은 `uv.lock` 그대로 설치한다. 락과 `pyproject.toml` 이 어긋나면 실패한다.

### 의존성 추가·변경

```bash
uv add pandas               # 실행 의존성
uv add --dev pytest-xdist   # 개발 의존성
uv lock                     # pyproject.toml 을 직접 고쳤을 때
```

`uv.lock` 변경은 해당 PR 에 포함한다.

## 재현성 3계층

| 계층 | 정의 위치 | 보장 범위 |
| --- | --- | --- |
| 버전 범위 | `pyproject.toml` | 호환 범위 |
| 정확한 버전·해시 | `uv.lock` | 동일한 패키지 트리 |
| OS·시스템 라이브러리 | `Dockerfile`, `.devcontainer/` | 동일한 실행 환경 |

## Dev Container

`.devcontainer/devcontainer.json` 은 공식 Python 3.13 이미지를 쓰고, 생성 시 uv 설치 → `uv sync --frozen` → pre-commit 훅 설치를 수행한다. ruff·mypy·python·jupyter 확장이 함께 설치되고 인터프리터는 `.venv` 로 설정된다.

## Docker

`Dockerfile` 은 3단계다.

| 단계 | 하는 일 |
| --- | --- |
| `uv` | uv 바이너리 확보 |
| `builder` | `uv sync --frozen --no-dev --no-editable` 로 `.venv` 구성 |
| `runtime` | `python:3.13-slim` 에 `.venv` 만 복사, 비루트(`app`) 사용자로 `python -m setup1` 실행 |

`docker-compose.yml` 의 `app` 서비스가 런타임 이미지를 빌드한다. 데이터 저장소가 필요하면 같은 파일의 주석 처리된 `db` 서비스를 사용한다.

## 로컬 (bare metal)

`uv` 만 있으면 된다. `uv` 가 `.python-version`(3.13)에 맞는 Python 을 자동으로 내려받아 `.venv` 를 만든다. 시스템 Python 이나 conda 와 섞이지 않는다.
